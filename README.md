# ICD Social Studio

A browser tool for ICD staff: it adds the ICD logo, frames and watermarks to photos for social media.

**Open it:** https://jouamou.github.io/icdsm/

- **Banners** for LinkedIn, X, Facebook and YouTube, at each platform's size
- **Posts** in square, portrait, story and landscape formats, with an optional headline (Arabic is set right to left)
- **Watermark photos** in batches, downloaded as one ZIP
- **Profile pictures** sized for every platform's circular crop

Everything runs in your browser. Photos are never uploaded. It works best in Chrome or Edge on a computer.

The ICD name and logo belong to the Islamic Corporation for the Development of the Private Sector. Use them only for ICD communications, following the brand guidelines.
